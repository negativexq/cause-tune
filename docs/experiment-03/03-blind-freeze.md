# Experiment 03 — Blind Generalization Protocol

Experiment 03 uses `incident-blind-v2`, generated by the independent
`causetune.benchmark_blind_v2` namespace. The module reuses only the frozen
taxonomy and target schema; its narrative templates, case ordering and
topology assignment are separate from the Experiment 02 generator.

Before any model output is read, the freeze command writes the split files,
ground truth and manifest:

```bash
python scripts/freeze_experiment_03_blind.py \
  --output data/incident_diagnosis_blind_v2
```

The manifest freezes the benchmark fingerprint, generator version, scorer
version and contamination audit. Exact packet overlap with the old training,
validation or benchmark sources is blocking. After this point the benchmark,
scorer and prompt contract are immutable; no tuned result is available to the
freeze step.

The one-shot protocol is fixed as:

1. load the frozen V2 and evaluation contract;
2. evaluate untouched base once;
3. fresh-reload the already-selected E02 adapter once;
4. evaluate tuned once; and
5. compare persisted raw predictions offline.

No checkpoint shopping, prompt modification or result-informed regeneration is
permitted.
